# MLB Data Analysis | MySQL

## Project Overview
This project explores Major League Baseball (MLB) data using MySQL to investigate schools, player salaries, career statistics, and player comparisons.

## Database
- Database: Maven Advanced SQL
- SQL Language: MySQL

## Project Analysis

### 1. School Analysis
- Number of schools producing players across decades.
- Top 5 schools producing the most players.
- Top 3 schools for each decade using window functions.

### 2. Salary Analysis
- Top 20% of teams by average annual spending.
- Cumulative team spending over the years.
- First year each team's cumulative spending exceeded $1 billion.

### 3. Player Career Analysis
- Player debut age and ending age.
- Career length calculations.
- Starting and ending teams.
- Players who started and ended their careers with the same team.

### 4. Player Comparison Analysis
- Players sharing the same birthday.
- Batting preference distribution across teams.
- Changes in average player height and weight across decades.
